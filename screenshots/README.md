# Screenshots

Store sanitized Azure Portal screenshots here as evidence of configuration and validation.

Suggested evidence:
- Resource group and tags
- VNet address space and subnet list
- NSG rules
- VM configuration and connectivity tests
- Entra ID / RBAC configuration
- Monitoring and query results

**Definition — Evidence:** A screenshot or test result that supports a documented claim.

Before uploading, redact subscription IDs, tenant IDs, email addresses, public IPs where appropriate, and any secrets or personal information.
